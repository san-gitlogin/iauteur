# Channel Playbook — the strategy brain (from forensic analysis of 30+ reference-channel videos)
Production quality decides retention; THIS decides whether anyone arrives. Topic selection ≈ 80% of outcome.

## 1. TOPIC VERDICT (mandatory Stage 0.5 — before ANY writing)
Score the topic on four axes; greenlight needs ≥2. Record as meta.topicAxes (linter warns otherwise).
- **entity-novelty** — a NAMED thing launched/changed within ~7 days with low search supply. Verify by WEB SEARCH now (entity age + how much content already ranks). The strongest single predictor.
- **economic-pain** — a hard dollar/price/cost angle ($400→$5, 11x price trap, $0/token local).
- **sovereignty** — local-first, self-hosted, privacy, anti-lock-in (this audience: cost-conscious mid/senior devs).
- **tribal-conflict** — challenger vs resented incumbent (React, Docker, LangChain, CUDA, vector DBs...).
FAILURE RULE: theory without a deadline dies. Deep evergreen explainers (how GPS works, MoE, quantization, X vs Y basics) compete with a decade of giants — score 0-1 axes → tell the user plainly: "this profile historically lands ~50-300 views" and web-search 3 entity-fresh alternatives in the same interest area. User may overrule; the verdict must be stated.

## 2. SEQUEL ENGINE (exploit validated winners, fast)
Maintain topics/ledger.json: {entity, slug, date, axes, validated: bool (set true when the user reports it performed)}.
When an entity validates: within 24–72h propose the Cartesian product against OTHER validated entities and the audience's staple tools: "[NewEntity] + [ValidatedEntity]". Expect the decay curve: entity and entity+entity videos peak; wiring tutorials draw fewer but deeper viewers — make both, know which is which.

## 3. TITLE TEMPLATES (pick ONE per video; A>B>C>D; E is banned)
A **Entity-stack**: "[New Entity] + [Known Entity] …" — highest performer; the "+" signals integration intent.
B **Replacement**: "[Incumbent] is Dying: [Challenger] …" — ONLY when the video substantiates the claim with evidence.
C **Prohibition**: "Stop Using [X] (Use This Instead)" — only against genuinely fresh alternatives, never saturated targets.
D **Quantified stakes**: a hard, sourced number in the title (85% faster, $400→$5) — the number is a falsifiable claim; that's WHY senior devs click. Number must appear in the video.
E **Neutral descriptive** ("X vs Y", "How X Works") — the statistically proven loser; banned as a primary title, allowed only as a suffix.
INTEGRITY LINE (non-negotiable): every title claim must be paid off in the video. Hype words ("INSANE") max once per title and only when the content is genuinely surprising; dishonest packaging trades one video's clicks for the channel's trust and YouTube standing.

## 4. DESCRIPTION — fixed 7-block skeleton, in order
1) Hook question restating the title's tension (1-2 lines — these show before "…more").
2) 2-3 paragraphs, the FIRST opening with the channel's branded anchor phrase from channel_profile (e.g. "In this video, <Channel> breaks down…") — verbatim, every video: it trains the entity association in search.
3) Chapters — GENERATED by `npm run chapters -- <slug>` (never hand-computed; this mechanically prevents the impossible-timestamp class of leak). Keyword the labels.
4) Resources & References — REAL links only (official docs, repos, papers actually used). Authority signal; inventing links is a Truth Law violation.
5) Subscribe CTA with the channel slogan from the profile, verbatim.
6) Socials (from profile).
7) User Queries + hashtags (below).

## 5. USER QUERIES + HASHTAGS
- 8-14 simulated autocomplete strings — multi-word natural language exactly as a dev would type ("<entity> claude code setup json config"). 
- Adjacent/competitor queries ONLY when the video meaningfully addresses them (a comparison, a mention with substance). Intent-hijacking for absent content poisons retention and risks spam policy — the reference channel's stuffed HTMX block is the cautionary tale.
- Seed ONE branded query per video ("<channel name> <topic category>").
- Hashtags: exactly 3 in this order — #<trending-entity> #<broad-category> #<brand>. The first three render above the title on mobile: the entity tag is part of the packaging.

## 6. WATCH NEXT — maintain the chain (the reference channel's biggest unforced error)
Every description's "Watch next" points to the channel's CURRENT best performer or the most related validated video — read it from channel_profile (WATCH_NEXT field) and UPDATE the profile whenever a new video validates. Never let it fossilize into a dead end.

## 7. ANTI-LEAK QA (their pipeline artifacts = our checklist)
Before emitting any public text, verify: no internal instructions/scoring notes in titles or descriptions ("crucial for rich snippets", "timely and underserved"); no scene IDs, float seconds, or JSON field names; all timestamps valid mm:ss (seconds < 60 — use the script); exactly ONE channel handle everywhere; no typos in the title (spell-check it explicitly). Publishing pipeline artifacts is a firing offense for the pipeline.
