## COMPONENT PALETTE (17 types — use ONLY these; each with its exact data schema)
(`!`=required · `?`=optional · `≤N`=max chars · anchors: `at:"word"` copied from the scene’s narration)

HOOK — First ≤8s. State the stake so the viewer cannot scroll.
    USE: Always scene 1.
    data: { headline!≤30:string — the big line, subtext?≤48:string, heroAsset?:asset — usually lucide: naming the topic, headlineAt?:"word from narration", heroAt?:"word from narration" }
    ex: {"headline":"DEAD IN 3 DAYS","subtext":"a 72-hour lifespan","heroAsset":"lucide:skull","headlineAt":"dead","heroAt":"dead"}

TITLE_CARD — Name the topic for 2-3s after the hook.
    USE: Right after HOOK.
    data: { title!≤48:string, subtitle?≤48:string }
    ex: {"title":"Muse Image","subtitle":"the 72-hour lifespan"}

CONCEPT_DIAGRAM — How-it-works chain of 2-4 nodes + edges.
    USE: Explain a mechanism/flow.
    data: { nodes!:items — 2-4 × {id, label≤18, asset?, atWord}, edges?:items — {from, to, atWord} }
    ex: {"nodes":[{"id":"n1","label":"Public posts","asset":"lucide:image","at":"public"},{"id":"n2","label":"AI model","asset":"lucide:cpu","at":"ai"}],"edges":[{"from":"n1","to":"n2","at":"here"}]}

KINETIC_TEXT — A single line as a dynamic moment (8 FX).
    USE: A punch, breather, or statement where static text would feel flat.
    data.kinetic: { text!≤48:string, fx?:string — typewriter|glitch|split|char-spin|highlight|bounce|wave|outline|pop|pulse|slide, sub?≤40:string, color?:string, at?:"word from narration" }
    ex: {"kinetic":{"text":"Predict the next token.","fx":"typewriter","sub":"that's the whole trick","color":"blue","at":"predict"}}

STEP_FLOW — Pipeline of 3-5 named stages.
    USE: A sequential process (RAG, CI/CD).
    data: { steps!:items — 3-5 × {kicker?, title≤14, sub?≤30, color?, atWord}, source?≤64:string }
    ex: {"steps":[{"title":"Ingest","sub":"load docs","at":"ingest"},{"title":"Embed","sub":"to vectors","at":"embed"},{"title":"Answer","sub":"grounded","at":"answer"}],"source":"illustrative"}

LIST_BUILD — "N things this changes" — icon list, two-tier rows.
    USE: Enumerate 3-5 points.
    data: { heading?≤48:string, items!:items — 3-5 × {icon?, text≤44, detail?, atWord} }
    ex: {"heading":"A familiar pattern","items":[{"icon":"lucide:video","text":"OpenAI Sora 2","detail":"shut down 2025","at":"openai"},{"icon":"lucide:copyright","text":"Trademark issues","detail":"studios angered","at":"trademark"}]}

RECAP — Close the hook loop: 3-4 points.
    USE: Penultimate scene.
    data: { heading?≤48:string, points!:items — 3-4 × {text≤46, atWord} }
    ex: {"heading":"The short life of Muse Image","points":[{"text":"Launched Tuesday","at":"launched"},{"text":"Privacy panic","at":"privacy"},{"text":"Killed by Friday","at":"killed"}]}

STAT_CALLOUT — ONE hero number counting up (+ optional logo strip).
